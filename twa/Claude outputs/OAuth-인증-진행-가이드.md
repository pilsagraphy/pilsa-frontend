## 2. 해야 할 일 — 순서대로

### ① 앱 로고 업로드 (내가 못 함 — 파일 필요)

- 규격: **120x120 정사각형**, JPG/PNG/BMP, 1MB 이하
- `twa/store_icon.png` 나 `public/icons/` 의 아이콘을 리사이즈하면 됩니다
- 업로드 위치: 콘솔 → 브랜딩 → 앱 로고

### ② 서비스 약관(이용약관) 페이지 만들기 (초안은 내가 씀)

`help.pilsa.co.kr` 에 개인정보처리방침·계정 삭제·이용 제한·아동 안전 표준은 있는데 **이용약관이 없습니다.**

OAuth 인증에서 서비스 약관 링크는 사실상 필수입니다. 필요하시면 초안 써드리겠습니다. 기존 문서 톤에 맞춰서 쓰면 반나절이면 됩니다.

### ③ 도메인 소유권 확인 (내가 못 함 — 계정 작업)

Google Search Console에서 `pilsa.co.kr` 소유권을 확인해야 합니다. **OAuth 프로젝트와 같은 구글 계정**(qkrwm207@gmail.com)으로 해야 합니다.

- https://search.google.com/search-console
- 속성 추가 → 도메인 또는 URL 접두어 → DNS TXT 레코드 또는 HTML 파일로 확인

이미 돼 있으면 건너뛰세요.

### ④ 앱 이름 통일 여부 결정

콘솔은 `필사그래피`, Play는 `Pilsagraphy` 입니다. 심사자가 동의 화면과 실제 앱을 대조하는데, 이름이 다르면 확인 절차가 늘어날 수 있습니다.

Play 앱명이 `Pilsagraphy`이니 콘솔도 맞추거나, `Pilsagraphy (필사그래피)` 처럼 둘 다 넣는 방법이 있습니다.

### ⑤ 데모 영상 촬영 (내가 못 함 — 촬영 필요)

민감한 범위 인증에서 **가장 손이 많이 가는 항목**입니다. YouTube에 공개 또는 일부공개로 올리고 링크를 제출합니다.

영상에 반드시 들어가야 할 것:

1. 앱 실행 → 로그인
2. 마이페이지에서 **구글 캘린더 연동 버튼을 누르는 장면**
3. **OAuth 동의 화면 전체** — 앱 이름과 요청 범위가 화면에 보여야 함
4. 동의 후 앱으로 돌아오는 장면
5. 동아리 일정이 **실제 구글 캘린더에 등록된 결과**

음성 설명은 없어도 되지만, 자막으로 각 단계를 표시하면 통과율이 올라갑니다.

### ⑥ 범위 사용 정당성 작성 (초안은 내가 씀)

`calendar.events` 를 왜 쓰는지, 왜 더 좁은 범위로는 안 되는지 설명해야 합니다. 아래는 초안입니다.

```
필사그래피는 경희대학교 동아리의 재학생·졸업생 회원만 이용하는
폐쇄형 커뮤니티 앱입니다.

운영진이 앱에서 동아리 일정(정기 모임, 워크숍, 전시 등)을 등록하면,
연동에 동의한 회원의 구글 캘린더에 해당 일정을 자동으로 생성합니다.
일정이 변경되거나 취소되면 이미 생성한 일정을 수정·삭제해야 하므로
calendar.events 범위가 필요합니다.

더 좁은 범위로는 구현할 수 없습니다. calendar.events.readonly 는
읽기만 가능해 일정 생성이 불가능하고, calendar.app.created 는 앱이
만든 전용 캘린더에만 접근 가능해 이용자가 평소 사용하는 기본 캘린더에
일정을 넣어달라는 회원 요구를 충족할 수 없습니다.

앱은 동아리 일정에 해당하는 항목만 생성·수정·삭제하며, 이용자의 기존
일정을 읽거나 변경하지 않습니다. 연동은 전적으로 선택 사항이고,
마이페이지에서 언제든 해제할 수 있으며 해제 시 저장된 토큰을 즉시
파기하고 구글에 권한 회수를 요청합니다.
```

> ⚠️ **확인 필요**: 위 "더 좁은 범위로는 안 되는 이유" 부분은 제가 일반적인 캘린더 API 범위 기준으로 쓴 것입니다. 실제 구현이 기본 캘린더가 아니라 전용 캘린더를 만드는 방식이라면 `calendar.app.created` 로 낮출 수 있고, 그러면 **인증 자체가 훨씬 수월해집니다.** 백엔드 코드 확인해보시고 알려주시면 다시 쓰겠습니다.

### ⑦ 게시 + 인증 제출

①~⑥ 끝난 뒤에:

1. 콘솔 → 대상 → **`앱 게시`**
2. 콘솔 → 인증 센터 → 인증 제출
3. 영상 링크, 범위 정당성, 각 항목 입력
