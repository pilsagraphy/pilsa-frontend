## C. Play 의견으로 남겨 달라고 부탁할 문구 (사람별 복사용)

Play 스토어 앱 → 참여 링크로 Pilsagraphy 앱 페이지 열기 → 아래쪽 "테스터 의견 보내기"에 붙여 넣기

**박수민**
```
1. 달력에서 날짜를 누르고 일정 추가를 하면 오늘 날짜만 들어가요. 누른 날짜가 자동으로 들어가면 좋겠어요.
2. 동아리 소개 메뉴(소개·연혁·명예의 전당 등)에서 뒤로가기를 누르면 엉뚱한 페이지로 이동해요.
3. 활동 사진 설명글을 확대 화면에서도 보거나, 길게 누르면 볼 수 있게 해 주세요.
4. 일정 날짜 선택 창이 너무 커요.
```

**가성연**
```
1. 뒤로가기를 누르면 목록으로 안 가고 시작 화면(시계)이 계속 반복돼요.
2. 가끔 게시글을 눌러도 안 넘어가고 오류 화면이 떠요.
```

**김예령**
```
1. 글이 단어 중간에서 줄바꿈되어 잘려 보여요.
2. 게시글에 들어갔다 나오면 목록 맨 위로 올라가요. 보던 위치 그대로 있으면 좋겠어요.
```

**이민승**
```
앱을 켜자마자 메인이 뜬 상태에서 스크롤하거나 게시글을 누르면 오류 화면이 뜨고 넘어가지 않을 때가 있어요.
```
